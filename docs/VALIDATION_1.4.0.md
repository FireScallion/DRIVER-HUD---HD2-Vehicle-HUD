# DRIVER HUD 1.4.0 — 实现与验证报告

## 交付状态

1.4.0 生产代码、安装包、统一 Nexus/GitHub Release 包及可重建源码均已完成。以下测试是本轮实际执行的结果，不沿用旧版报告。

**运行环境边界：本容器没有 LuaJIT 可执行文件，也没有 Windows/HD2。实际采用 TeX Lua 5.3 + tests/run_lua53.lua 的 Lua 5.1 环境装载适配执行生产载荷；Win32 适配器测试使用真实 owned FFI buffers 和模拟 Win32 函数。不能把这称为 LuaJIT 实机、网络同步实机或 FPS 验收。** 目标游戏运行时仍为 LuaJIT；实现未引入 Lua 5.2/5.3 专属语法。替代执行器只用于测试，不部署到游戏。

## 实际改动

- 新增 `src/tank_runtime.lua`：新坦克限定资源 `b0c9faf4af8903f9`，复用已经确认的当前 Hull。绑定来源是 Hull 的第 56 项显式子对象引用，不用 Hull±N 或距离猜选。
- 只在最多五个显式子对象内，用已采样的结构指纹分类加特林和两路导弹架。加特林读取 #6/#7/#28；两路导弹架读取 #18。没有采用最初被误判的 `Hull-3 #6=20` 对象。
- 不使用 0.6 未验证通过的类型别名，不调用未知 targeted getter。保留已有批量读取路径的参数方式、四次/帧与 40 次/秒总预算。
- 稳态新武器**共用** 10 Hz 查询时隙：加特林最多 5 Hz，两侧导弹架各最多 2.5 Hz；车体 5 Hz。没有探针的 20 Hz 遥测、全场/近邻 GOID 扫描、远端玩家 owned 列表枚举。
- 车体引用字段暂时缺失不等于武器移除；停止使用过期引用发新查询，但保留 last-valid。显式引用集合改变/对象消失/换车时清对应状态。数据越界、部分样本或 NIL 不被换成 0。
- 新增 `src/tank_ui.lua`：加特林当前弹链条 + 六格备用条在左，导弹数字在右。原版坦克保留主炮/同轴布局。新坦克总框稍加宽，以保留数字和两条状态条的间距。
- 新旧坦克均有装填环。环与静态 HUD 分开保存绘制 IDs；环变化不重建车体数字、生命条和准星。复用 1.3.5 同材质几何数字，未改 FRV 原有几何及配色。
- `position_config.lua` 增加 AppData 外部双语 TXT，约两秒热加载，首建迁移合法旧 JSON。支持 UTF-8/BOM、CRLF、Notepad UTF-16 LE/BE；缺项/重复/越界/半写保留上次有效值。没有 loadstring 或执行配置内容。
- 移除包内 CMD/PowerShell 图形配置器。统一主包直接用于 Arsenal、GitHub Release 和 Nexus Main；Nexus 命名包只是同一字节内容的别名。

## 装填事实和显示边界

旧主炮日志中，约三秒是炮弹入膛提交点，后面还有约一秒最终动作（7 → 4 → 0）。因此弹药记账和完整提示环不共用一个“3 秒结束”开关。新弹链样本约四秒。

加特林备用弹链始终由有效游戏样本提供，绝不因 R、动画时间到达或入座次数自己扣减。主炮和加特林归零不自动触发装填。

已观察到的暂停/恢复以同一车辆身份保存进度；换会话、换头像、换车以及子对象集合改变不会继承他车数据。离座缓存有数量和时间上限，回车后先核对库存/周期。驾驶员离开时不能假设仍在操作的远端炮手也暂停。

**环是状态驱动的显示估计，不是游戏的原生连续进度值。** 首次遇到已经进行/暂停的装填而没有开始时间，显示静态点状环。短读允许很短的显示宽限；装填状态超过一秒无新样本时停止外推，转为保持/不确定，不假装完成。长缺口期间可能不能完整呈现远端炮手的暂停/恢复，但不会因此编造弹药或就绪状态。

超过三秒没有新读数的弹药显示变暗并带虚线下划线，明确为最近一次有效值。未取得两路导弹有效数据时不把缺失那一路当作零相加。

此前探针的 GAP 包含共享采样预算/调度的可能影响，不能仅凭旧 GAP 日志就断言游戏网络接口天生无法稳定读取。本实现去掉叠加探针工作，保持有界且公平的生产调度；实际网络可读性仍需游戏内观察。

1.4 主测试和 TXT 测试均重复运行。真实采样回放使用去除玩家身份的数值事件；变化日志之间扩展为健康低频采样，只验证状态机对这些转换的处理，**不验证远端接口的采样成功率**。

144 Hz 模拟更新、稳定乘坐十秒：新坦克批量读数共 146 次，其中加特林 48 次，两侧导弹各 24 次。此为模拟 API 调用数量，不是游戏 CPU 毫秒或 FPS 数据。旧坦克装填检测增加最多 5 Hz 的单个已确认主炮样本；未抬高原主炮/机枪读数频率。

## 保持不变的部分

1.3.5 `src/native_reader.lua` 和 `src/frv_ui.lua` 按字节保留。原 1.2.1 坦克弹药/刷新块、原引用 resolver、原 draw 块由构建器逐字校验；1.4 通过独立包装入口扩展，而不是改写这些块。唯一新增原版坦克读取是低频装填检测。

原 module PE + 14 处代码门、FFI 只读 adapter、FRV Health 独立容错保留。素材、GPU/stream 文件与 1.3.5 基准相同。二进制 bundle header 除两个长度值外逐字一致，不经 UTF-8 解码。包不含游戏 DLL、进程快照、字体或外部可执行工具。

## 仍需真实游戏确认

新安装包在本地炮手/驾驶位的表现、远端装填提示可读性、实际曲率设置下的新装填环、最终 FPS，以及 Nexus 的实际扫描结果。移除配置器减少了分包需求，但不保证第三方扫描必过。

最终使用时：先禁用旧 HUD/Probe，部署本包；短验原版坦克、新坦克和 FRV 即可，不要求再跑研究探针。
