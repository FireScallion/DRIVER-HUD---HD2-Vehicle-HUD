# Contributing

Research, bug reports, forks, and experimental extensions are welcome.

DRIVER HUD is maintained as a small personal project, so there is no guarantee that external pull requests will be reviewed or merged on a particular schedule. If you want to experiment with new vehicles, UI layouts, or alternative implementations, maintaining your own fork is completely fine.

## Pull Requests

If you submit a pull request, please try to keep it focused and explain:

- what problem or feature it addresses;
- which vehicle, seat, or network object it affects;
- whether the change alters native/network read frequency;
- what in-game scenarios were tested.

Avoid broad refactors bundled together with unrelated feature work when possible. Stability and maintainability take priority over adding many features at once.

## Bug Reports

For runtime issues, include `driver_hud.log` when possible:

```text
%APPDATA%\Arrowhead\Helldivers2\driver_hud.log
```

Please also mention the seat you were using, whether you changed vehicles, whether multiple vehicles were present, and what happened immediately before the issue.

## Third-Party Material

Only submit code or assets that you have the right to contribute. Third-party material remains subject to its own license or permission terms.
