DRIVER HUD 1.3.5 — 调度与性能说明 / Scheduling notes

1.3.5 保留 1.3.4 的调度优化；本次不是进一步降频。
Stable ownership enumeration remains about 5 Hz. Relation and FRV Health polling
remain about 10 Hz. Tank ammo sampling/counting logic is unchanged. Seat exit,
avatar/session changes and rendering checks still run every update.

图形只在数据或布局变化时重建；新几何数字也使用同一 retained GUI 生命周期。
The geometry numeral option adds triangles to each rebuilt HUD, but unchanged
frames do not recreate them. This is not a measured guarantee of unchanged FPS.

新版 native 布局已适配本次游戏构建；样本内可读区域检查缓存、RPM 完整长度检查、
相邻身份监视项合并复查与全部身份校验均保留。
Memory protection metadata is only cached for one synchronous sample. RPM still
checks every copy. Dynamic game values and component addresses are not cached
across samples as permanent identity.

测试是离线合成数据和 LuaJIT FFI 封装模拟，不是 Windows 游戏 FPS 测试。
Developer tests: luajit tests/test_performance.lua .

可选统计 / Optional diagnostics:
  %APPDATA%\Arrowhead\Helldivers2\driver_hud.cfg
  debug=true
  perf=true
修改后重启。约每 10 秒写一条 PERF；统计的是 HUD 更新的 CPU 时间估计和内存
读取请求次数，不包含 GPU 时间或原游戏 update。测试后改回 perf=false。

Replace old DRIVER HUD versions rather than enabling them together.
Do not disable game protection or elevate permissions to make this mod work.
